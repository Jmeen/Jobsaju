# JobSaju Design System

**직장인 이직사주 (JobSaju / jobsaju.kr)** — 사주로 나만의 "직장생활 수호신"을 찾아 공유하는 마이크로 유료 앱의 디자인 시스템.

한 줄 정의: 생년월일시를 입력하면 60갑자 기반 수호신 캐릭터를 보여주고, 무료 결과(수호신 정체성 + 궁합)로 애착을 만든 뒤, 이직·잔류·협상 3대 커리어 점수와 6개월 로드맵을 1회성 결제(2,900원)로 해금하는 Freemium 앱.

## 소스

- 코드베이스: `job_saju_codex_handoff/` (로컬 첨부 폴더, React + TypeScript + Vite)
  - 제품 기획: `job_saju_codex_handoff/README.md`, `DECISIONS.md`, `PRODUCT_SPEC.md`, `UX_FLOW.md`
  - 실제 화면 구현: `src/components/screens/*.tsx`, `src/components/guardian/*.tsx`
  - 디자인 토큰 원본: `src/styles/guardian.css` (`--jg-*` 커스텀 프로퍼티)
  - 60갑자 수호신 데이터: `src/utils/guardianProfiles.ts`, `guardianAssets.ts`, `guardianChemistry.ts`, `guardianShareCard.ts`
  - 목업: `docs/mockups/guardian-flow/guardian-flow-mockup.html` (구현의 시각적 근거)
- 업로드 폰트: `uploads/NanumGothic.otf`, `uploads/NeoDunggeunmoPro-Regular.woff`
- 이 문서를 읽는 사람이 위 경로에 접근하지 못할 수 있음을 감안해 이 design system 자체에 필요한 값·에셋을 모두 복제해 두었다.

> **중요**: `DECISIONS.md`의 "다크 모드 / 테크&네뷸러" 콘셉트는 초기 기획안이며, 실제 구현(`guardian.css`, 목업, 스크린샷)은 **따뜻한 아이보리·베이지 라이트 톤**으로 확정되어 있다. 이 디자인 시스템은 실제 구현을 기준으로 삼는다.

## 콘텐츠 펀더멘탈 (Content Fundamentals)

- **화자 관계**: 앱은 사용자에게 반말이 섞인 다정한 존댓말로 말한다. "~해요/~돼요" 톤이 기본이며, 수호신 캐릭터의 대사는 문장 끝에 캐릭터 특징 어미가 붙는다 (예: "~용", "~양", "~쥐", "~소" — 12지 동물 이름의 마지막 음절을 어미처럼 살린 말장난).
- **인칭**: "당신"은 거의 쓰지 않는다. 대신 "내 수호신", "너는?"처럼 소유격+반문으로 친밀감을 만든다. 공유 CTA의 "너는?"이 브랜드 목소리의 핵심.
- **캐릭터 이름 작명 공식**: [행동/성향 형용사] + [12지 동물] 또는 동물 어미 말장난. 예: 저지르쥐, 조금늦소, 센척호랑이, 볼빨간토끼, 일단크게용, 결국양보양, 짤랑쥐, 새싹호랑이, 예민보스토끼.
- **캐릭터 카피 공식**: 항상 "장점처럼 보이는 특성, 그런데 ~한 단점" 구조의 반전 한 문장. 예: "기회는 남들보다 먼저 채가는데, 뛰어가다 씨앗을 다 흘리고 온다." — 완벽한 존재가 아니라 **귀엽게 어설픈 동료**로 그린다. 이 반전 구조는 60종 전원에 예외 없이 적용된다.
- **숫자 표기**: 점수는 절대 %로 쓰지 않는다. "이직운 82점", "직장 케미 92점"처럼 "라벨 + 점수" 문장형. 잠긴 숫자는 블러 처리로 궁금증만 남긴다.
- **이모지**: UI 크롬(버튼, 라벨)에는 쓰지 않는다. 오직 (1) 캐릭터 대체 이모지(그림 로드 실패시 폴백), (2) 고민 선택지 아이콘(🧭🚪🌱), (3) 체크마크(✓)에만 제한적으로 사용.
- **금지 표현**: "무조건 이직하세요" 같은 단정형 결정 대행 문구, 사주 용어 나열(십성/신살 등 원문 그대로 노출 금지 — 항상 직장인 언어로 번역), 개인정보(생년월일 등) 노출.
- **공유 문구 공식(고정)**: "내 수호신은 ○○. 너는?" → [친구에게 물어보기] 하나만. 여러 CTA를 늘어놓지 않는다.

## 비주얼 파운데이션 (Visual Foundations)

- **팔레트**: 따뜻한 아이보리(`--color-page #faf8f2`)와 베이지 카드(`#f3f0e7`) 위에 세이지 그린 브랜드 컬러(`#66866e`) 하나만 UI 크롬(버튼/링크/브랜드 텍스트)에 쓴다. 채도 높은 색은 오행 5색군(목/화/토/금/수)뿐이며, 이 색은 **캐릭터 이름 라벨, 배지, 오행 CTA 테두리, 공유 카드 tint**에만 제한적으로 등장한다 — 화면 전체 배경이나 내비게이션에는 쓰지 않는다.
- **타이포그래피**: Display(수호신 이름 전용, 둥글고 친근한 인상) + Body(본문, 가독성 우선) 2단 구성. 폰트 크기는 9.5px~28px 사이 소형 스케일 — 모바일 단일 컬럼 카드 UI라 큰 헤드라인이 필요 없다.
- **배경**: 이미지·패턴·그라데이션 배경 없음. 순수 단색 아이보리 배경 위에 베이지 카드로 위계를 나눈다. 유일한 그라데이션은 랜딩의 "?" 미스터리 블롭(`linear-gradient(180deg,#dfe8e1,#cbd7ce)`)과 공유 카드의 은은한 오행 tint 그라데이션뿐이다.
- **일러스트/이미지**: 손그림 톤의 파스텔 컬러 펜슬 일러스트 캐릭터(60갑자 수호신) — 배경 없이 누끼(투명 배경) PNG/WebP. 실사, 3D, 벡터 플랫 아이콘 스타일 캐릭터는 쓰지 않는다.
- **애니메이션**: 최소한만 사용. 랜딩의 좌우 무한 마퀴(자동 스크롤), 소환 화면의 주머니 흔들림(`jg-pouch-shake`, 1s ease-in-out infinite), 수호신 실루엣 → 컬러 전환(opacity/blur/scale, 0.6s ease). `prefers-reduced-motion`을 항상 존중해 애니메이션을 끈다. 바운스나 통통 튀는 이징은 쓰지 않는다 — 전부 ease 계열의 차분한 전환.
- **호버 상태**: 대부분 없음(모바일 우선). 있는 곳(고민 선택 카드)은 `border-color`를 오행 액센트 쪽으로, 배경을 살짝 밝게(`color-mix`)만 바꾼다.
- **프레스 상태**: 배경을 한 단계 더 진한 톤으로(`--jg-guardian-pressed`) — 축소(scale) 효과는 쓰지 않는다.
- **테두리/그림자**: 기본 카드는 테두리 없이 배경색 차이(베이지 on 아이보리)로만 구분한다. 그림자는 캐릭터 드롭섀도(`drop-shadow`)와 소환 파우치 등 입체가 필요한 요소에만 은은하게(`rgba(*, .08~.18)`) 쓴다. 이너 셰도우는 쓰지 않는다.
- **투명도/블러**: 잠긴 유료 숫자를 `blur(4px)`로 가리는 용도, 수호신 소환 연출 중 실루엣(`blur(10px)`→`blur(3px)`)에만 쓴다. 유리(glassmorphism) 효과는 쓰지 않는다.
- **코너 반경**: 버튼 15px, 카드 16~18px, 인풋 11~13px, 배지/마퀴 칩은 완전 필(999px). 블롭 모양(파우치, 미스터리 캐릭터)은 비대칭 라운딩(`45% 45% 42% 42%`)으로 유기적 형태를 만든다.
- **레이아웃 규칙**: 모바일 단일 컬럼, 최대 폭 390px, 좌우 여백 22px 고정. 헤더/푸터 고정 요소 없음 — 화면마다 스크롤되는 카드 스택 하나.
- **이미지 색감**: 파스텔, 밝고 채도는 낮은 편(그레인 없음, 따뜻한 색온도). 흑백/차가운 톤 이미지는 없음.

## 오행(五行) 컬러 시스템

사용자의 일간(태어난 날의 천간)에 따라 5가지 원소 중 하나가 배정되고, 그 색이 화면의 "지금 이 순간의 강조색"이 된다.

| 오행 | 액센트 | 소프트 배경 | 프레스 배경 |
|---|---|---|---|
| 목(木) wood | `#7fae9a` | `#eef6f1` | `#e5f1ea` |
| 화(火) fire | `#e99a88` | `#fff1ec` | `#fbe8e1` |
| 토(土) earth | `#c6a86b` | `#f7f1e3` | `#f1e8d4` |
| 금(金) metal | `#c7b27a` | `#f8f5eb` | `#f0eadc` |
| 수(水) water | `#7893ae` | `#eef3f8` | `#e4ebf3` |

**사용 범위(제한적)**: 캐릭터 이름 옆 라벨, "고민 물어보기" guardian 버튼의 테두리/배경, 고민 선택 카드의 선택 상태, 공유 카드의 tint. 본문 텍스트 색, 전역 배경, 내비게이션에는 쓰지 않는다 — 세이지 그린(`--color-brand`)이 항상 UI 크롬의 기준색이다.

## 아이코노그래피 (Iconography)

- 별도의 아이콘 폰트나 SVG 스프라이트 시스템은 없다. **이모지를 아이콘으로 직접 사용**하는 것이 이 브랜드의 방식이다 (예: 고민 선택지 🧭🚪🌱, 캐릭터 폴백 🐭🐮🐯…, 리스트 체크 ✓).
- 그림 로드 실패 시에도 자리를 비우지 않도록 캐릭터별 띠 이모지(`animalEmoji`)를 SVG로 감싸 data URI 폴백으로 렌더링한다 — `assets/guardians/`에 이미지가 없거나 깨져도 UI가 무너지지 않게 하는 안전장치.
- 커스텀 라인 아이콘 세트, PNG 아이콘 세트는 없음. 필요한 경우 이모지로 대체하고, 브랜드에 없는 스타일(선 굵기가 다른 아웃라인 아이콘 등)을 새로 만들지 않는다.
- 로고: `assets/logos/app-icon.png` (검정 원 + 금색 "職" 글자, 앱 아이콘), `assets/logos/kakao-icon-128.png` (카카오 채널 아이콘). **워드마크는 없다** — 화면 안에서는 "jobsaju.kr" 텍스트를 그대로 브랜드 표기로 쓴다. 별도의 로고 SVG를 새로 그리지 않았다.

## 컴포넌트 (Components)

소스 코드베이스에 정의된 실제 컴포넌트 인벤토리를 기준으로, 브랜드 규칙(오행 색, 케미 표기, 단일 공유 CTA)을 지키는 데 필요한 만큼만 구성했다.

**Core** (`components/core/`)
- `Button` / `TextLink` — primary·secondary·guardian(오행 액센트) 3종 CTA
- `Card` / `ScreenShell` — 베이지 카드, 390px 모바일 화면 셸
- `ScoreGrid` — 이직/협상/잔류 3분할 점수 그리드 (잠금 블러 지원)
- `ChemistryScore` — "라벨 + 점수" 형태의 궁합 칩
- `Badge` — 필 배지 (마퀴 칩, 태그)
- `CollectionBadge` — "No.51 · 60마리 중" 수집 배지 (참여·공유 강화용, 아래 항목 참고)

**Guardian** (`components/guardian/`)
- `GuardianPortrait` / `GuardianNameplate` — 60갑자 아트워크 + Display 폰트 이름
- `ChemistryBlock` — 찰떡+티격태격을 압축한 결과 화면의 유일한 공유 허브
- `ShareCard` — 60종 공통 솔로 공유 카드 템플릿, 1:1·9:16 (+ `drawShareCardToCanvas` PNG 렌더러)
- `ChemistryShareCard` — 궁합 비교 공유 카드, 1:1·9:16 — 단체 카톡방/친구 태그 2차 바이럴용
- `guardianData.js` — 60갑자 프로필/오행/케미 계산 공유 데이터 모듈 (컴포넌트 아님, 헬퍼)

### Intentional additions
소스에 이름이 명시된 컴포넌트가 아니라, 반복되는 UI 패턴(점수 그리드, 화면 셸, 배지)을 코드베이스의 실제 CSS 클래스(`.jg-scores`, `.jg-screen`, `.jg-marquee-chip`)에서 그대로 뽑아 이름 붙인 것들이다 — 코드베이스가 React 컴포넌트로 이미 분리해 둔 `GuardianImage`, `ChemistryBlock`은 이름까지 그대로 따랐다.

## UI 킷

## 캐릭터·컬러 개성 강화 방향 (다음 반복 메모)

브랜드 노트에 따라 다음 영역은 "15~20% 더 개성 있게" 다듬을 여지를 열어둔다 — 톤 자체(아이보리·베이지, 반전형 카피 공식, 단일 공유 CTA)는 유지한 채로:
- 캐릭터 이름의 반전 유머 강도를 소폭 강화
- 오행 5색을 배지/CTA/공유 카드에 더 대담하게(그러나 여전히 절제된 범위 안에서) 노출
- 공유 카드의 오행 tint 대비를 본 화면보다 한 단 더 세게 (이미 `ShareCard` 컴포넌트에 반영됨)

## 참여·공유 강화 (Shareability pass)

"수집형 카드" 감각을 더해 참여·공유 욕구를 높였다. 톤(아이보리·베이지, 절제된 오행 컬러)은 그대로 두고 아래만 더했다:
- **`GuardianPortrait`의 `glow` prop** — 오행 색 방사형 후광을 캐릭터 뒤에 깐다. 수호신 발표·공유 카드 등 "하이라이트 순간"에만 쓴다(목록/작은 썸네일에는 쓰지 않음) — 순간의 무게감을 만든다.
- **`CollectionBadge`** — "No.51 · 60마리 중"처럼 전체 중 몇 번째를 뽑았는지 보여준다. 포켓몬/트레이딩 카드류의 수집 심리를 빌려, "친구도 몇 번째인지 궁금하게" 만드는 장치. 결과 화면 이름 아래 + 공유 카드 좌상단에 배치.
- **공유 카드 리디자인** — 이중 테두리(오행 색 + 배경색)로 "카드"라는 물성을 강조하고, 캐릭터 뒤에 방사형 후광, 배경엔 오행 색 톤의 은은한 도트 텍스처(스티커 시트 느낌)를 얹었다. "너는 어떤 수호신일까?"는 필(pill) 버튼 형태로 눌러서 강조. 모두 기존 팔레트 안에서만 움직인다 — 새 색이나 그라데이션 슬롭을 더하지 않았다.
