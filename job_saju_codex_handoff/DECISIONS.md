# 확정 의사결정

## 1. 제품 포지셔닝

앱 이름(가칭): **직장인 이직사주**

목표:
- 종합 운세/사주가 아니라 **직장과 이직 의사결정만 깊게 다루는 Vertical Fortune App**
- 사용자가 앱을 설치한 후 몇 분 안에 유용한 결과를 얻도록 설계
- 커뮤니티, 게시판, DM, 사용자 간 상호작용 없음

핵심 질문:
> 지금 이직해도 될까?

핵심 결과:
- 이직 추천도
- 잔류 추천도
- 협상운
- 향후 시기별 행동 가이드

---

## 2. 사주 해석 방식

선택: **하이브리드형**

### 규칙 기반 영역
- 출생정보 → 사주 원국
- 대운/세운/월운 등 시간 흐름
- 직업/변화/이동 관련 신호
- 기본 점수 산출

### AI 영역
- 계산 결과를 사용자 상황에 맞게 자연어로 해석
- 직장인의 의사결정 언어로 변환
- 사용자의 현재 고민에 따라 중요도를 재정렬

### AI가 하면 안 되는 것
- 원국을 임의로 변경
- 같은 입력에서 기본 사주 결과를 매번 다르게 생성
- 근거 없는 확률형 단정
- “무조건 퇴사하세요” 같은 결정 대행

원칙:
> **사주가 판단의 뼈대이고, 현재 커리어 상황이 해석의 초점이다.**

---

## 3. 입력 방식

단순 생년월일시만 받지 않는다.

### 필수 입력
- 생년월일
- 출생 시간
- 성별 또는 사주 계산에 필요한 성별 정보
- 양력/음력 여부

### 커리어 상황 입력
최소 2~3문항.

예시 1:
현재 상황은?
- 적극적으로 이직 중
- 제안을 받고 고민 중
- 현 직장을 계속 다닐지 고민
- 퇴사 후 휴식/창업 고민

예시 2:
현재 직장에서 가장 큰 고민은?
- 연봉
- 성장
- 조직/상사
- 안정성
- 워라밸

예시 3:
가장 알고 싶은 것은?
- 언제 지원할지
- 지금 옮겨도 될지
- 제안을 수락할지
- 연봉 협상 타이밍
- 버티는 게 나을지

이 문항들은 사주 자체를 바꾸지 않는다.
**같은 사주 결과 중 무엇을 우선 설명할지 결정하는 개인화 컨텍스트**로 사용한다.

---

## 4. 플랫폼/기술 방향

선택: **반응형 모바일 웹 (Web-First)**

추천 스택:
- Frontend: React, TypeScript, Vite, Vanilla CSS / CSS Modules
- Hosting: Cloudflare Pages 또는 Vercel (정적 호스팅으로 고정 서버 비용 0원)
- Backend: Cloudflare Workers 또는 Supabase Edge Functions (API Key 보안을 위한 서버리스 프록시 게이트웨이)
- DB/Storage: 가입 과정 없이 브라우저 로컬 스토리지(LocalStorage) 활용

원칙:
- **Web-First, App-Later**: 반응형 모바일 웹으로 신속히 런칭하고, 추후 필요 시 Capacitor를 얹어 iOS/Android 앱으로 즉시 포팅할 수 있는 코드베이스 유지.
- **Serverless & Proxy**: 서버 호스팅비를 아끼고 AI API Key 보안을 철저히 유지하기 위해 서버리스 프록시를 징검다리로 활용.
- **No Membership**: 로그인 없이 결제 성공 시 발급하는 UUID나 브라우저 로컬 저장소로 결과를 영구 보존.

---

## 5. 비즈니스 및 결제 모델

선택: **Freemium & Unlock (무료 제공 후 1회 리포트 해금)**

원칙:
- **기본 무료**: 3대 커리어 점수(이직/잔류/협상) 및 한 줄 결론은 결제 없이 즉시 조회 가능.
- **유료 해금 (Unlock)**: 월별 흐름을 보여주는 이직 캘린더 타임라인과 AI가 직장인 언어로 해설하는 상세 리포트는 1회성 결제(예: 2,900원) 후 해금.
- **API 비용 제어**: 유료 해금을 결제한 유저에 한해서만 AI API(OpenAI/Gemini)를 호출함으로써 AI 연산 비용으로 인한 서비스 적자 차단.
- **웹 결제 최적화**: 포트원(PortOne) 또는 토스페이먼츠 연동으로 카카오페이, 네이버페이, 간편카드결제 지원 (앱 스토어 수수료 15~30% 대비 웹 결제 수수료 3~4% 수준으로 수익 극대화).

---

## 6. 디자인 및 시각화 원칙

- **Tech & Nebula Dark Mode**: 붉은색 부적 느낌을 탈피하고, 현대적인 테크 기업 대시보드 감성의 다크 모드(차콜, 다크 블루, 퍼플 포인트) 채택.
- **Data-Driven Visualization**: 지루한 정통 명리학 텍스트 대신 **오행 5각 레이더 차트 (나의 오피스 능력치)**, **이직 로드맵 캘린더 (월별 흐름)** 등 그래픽 중심의 직관적 해석 설계.
- **Screenshotable Card**: SNS(인스타그램 스토리, 블라인드) 공유 유도를 위해 개인 정보는 마스킹하고 세련된 그래픽의 '이직 캐릭터 카드' 이미지 생성 기능 지원.

---

## 7. 사이드잡 제품 원칙

- Single-player
- Instant gratification
- High-intent
- Low backend
- No moderation
- Paid-first (Freemium Unlock)
- Screenshotable result

금지:
- 커뮤니티
- 사용자간 거래
- 채팅
- 관리자 수동 검수
- 지속적인 콘텐츠 운영

핵심 운영 원칙:
> **사용자가 많아질수록 개발자가 더 바빠지는 앱은 만들지 않는다.**
