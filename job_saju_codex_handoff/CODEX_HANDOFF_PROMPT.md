# CODEX HANDOFF PROMPT

아래 프로젝트를 이어서 작업해줘.

## 프로젝트
직장인을 위한 **이직사주** 앱.

## 제품 한 줄 정의
생년월일시와 현재 커리어 상황을 입력하면,
정통 사주 계산 결과를 기반으로
이직/잔류/협상 타이밍을 직장인의 언어로 해석해 주는 앱.

## 중요 의사결정
- 종합 사주 앱이 아니다.
- 핵심 질문은 “지금 이직해도 될까?”
- 사주 계산은 deterministic/rule-based.
- AI는 계산 결과를 자연어로 해석하는 레이어.
- 사용자 입력은 생년월일시 + 현재 커리어 상황 2~3문항.
- 하나의 웹 기반 코드베이스로 iOS/Android를 노린다.
- React + TypeScript + Vite + Capacitor 방향.
- 커뮤니티/게시판/DM 없음.
- 회원가입은 MVP에서 제외.
- 서버는 최소화.
- 사이드잡이므로 운영 부담이 낮아야 한다.
