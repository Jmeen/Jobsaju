# UX FLOW — 잡사주

실제 구현된 화면 순서다. 랜딩은 캐릭터 바이럴 진입용으로 유지하고,
수호신 결과 이후부터 커리어 판단 가치가 자연스럽게 이어지도록 후단 퍼널을 설계했다.

```
landing → birth → summon → result(무료 수호신 + 커리어 신호)
        → paywall(왜·언제·어떻게) → [결제] → personalize → result(유료 리포트)
```

컴포넌트 매핑: `LandingScreen` · `BirthScreen` · `SummonScreen` · `GuardianResultScreen`
· `PaywallScreen` · `PersonalizeScreen` · `ResultScreen`.
(별도의 ‘고민 선택’ 화면은 제거되고, 무료 커리어 신호가 결과 화면 안으로 흡수됐다.)

---

## Screen 1. 랜딩 (LandingScreen)

**목표: 클릭.** 사주 설명 페이지가 아니라 **캐릭터 발견** 페이지다.
만들 감정: “캐릭터가 계속 바뀌네 → 이름이 웃기네 → 나는 뭐가 나올까 → 해봐야지.”

- 헤드라인: **60마리 중 내 수호신은 누구?**
- 서브: 직장인마다 하나씩 있는, 내 일머리 수호신 찾기
- 수호신 캐러셀 (색·이름이 바뀌며 흐른다)
- CTA: `내 수호신 뽑아보기`
- 보조 카피: **생년월일 입력 후 바로 확인 · 무료** (‘10초’ 같은 구체 시간은 쓰지 않는다)

공유 유도는 여기 두지 않는다 — 아직 자기 캐릭터가 없기 때문. 공유는 결과 화면에서 받는다.

---

## Screen 2. 출생정보 입력 (BirthScreen)

**목표: 완료 (최소 마찰).**

입력: 성별(필수) · 양력/음력 · 생년월일 6자리 · 태어난 시간(모르면 체크)

보조 카피:
> “입력한 정보는 내 수호신과 지금의 커리어 흐름을 확인하는 데 사용해요.”

(개인정보 수집·저장 정책과 충돌하지 않는 선에서 표현. 후단 커리어 분석과 단절되지 않게 한다.)

---

## Screen 3. 소환 연출 (SummonScreen)

**목표: 기대감.** 만세력 엔진을 백그라운드로 내려받는 동안(약 2.4초) 소환 애니메이션.
연출이 끝나면 사용자가 직접 `내 수호신 만나기`를 눌러 결과로 간다.

---

## Screen 4. 무료 수호신 결과 (GuardianResultScreen)

무료 구간의 핵심. 한 화면에서 스크롤로 이어지며, 두 가지를 준다:
(1) “나 같다”는 캐릭터 감각, (2) 그 결과가 실제 커리어 판단으로 이어진다는 신호.

### A. 수호신 결과 + 캐릭터 설명
- 캐릭터 이미지 · 이름 · 간지/오행
- 한 줄 성격 인용구
- **왜 이 수호신일까요?** — 짧은 근거 한 문단

### B. 같이 일하면 잘 맞는 유형 (ChemistryBlock · 공유 허브)
- **회사에서 찰떡인 유형** / **부딪히기 쉬운 유형** (관계 캐릭터는 작고 낮은 채도)
- 정교한 궁합 분석이 아니다 — **케미 점수 같은 수치는 노출하지 않는다.**
  목적은 세계관 확장 · 친구 떠올리기 · 공유 이유 만들기.
- CTA: `친구 수호신도 확인해보기` / 카카오톡 공유 · 링크 복사
- 공유 카드는 캐릭터·닉네임·한 줄 설명·“너는 누구?” 중심 (유료 상품 내용 아님)

### C. 무료 커리어 신호 (careerSignal)
캐릭터를 커리어 판단으로 잇는 다리.
- **이직 / 협상 / 잔류** 우선순위를 **◎ ○ △** 로 표시 (점수 수치는 없음)
- 한 문장 판단 (방향만): 예 *“지금은 안에서 버티기보다, 밖의 기회를 함께 열어두는 흐름이 강해요.”*
- 범례: ◎ 지금 우선 · ○ 여지 있음 · △ 지금은 아님
- 다음 질문(유료로 넘기는 다리): *“그런데 왜 지금 이직 흐름이 열릴까요? 언제 움직이는 게 좋을까요?”*
- CTA: `내 6개월 커리어 흐름 보기 →` · 부제 `왜 유리한지 · 언제 움직일지 · 어떻게 행동할지`

> 무료는 여기까지 — **“그래서 지금 뭐가 유리한데?”** 까지만 답한다.
> 세부 점수·긴 분석·타이밍·행동은 주지 않는다.

---

## Screen 5. 유료 전환 (PaywallScreen)

**목표: 결제.** “정보량을 더 사는 느낌”이 아니라 **왜·언제·어떻게**를 판다.
무료에서 ◎였던 축을 그대로 이어받아 헤드라인을 만든다.

- 헤드라인: **왜 지금 {이직/협상/잔류}이 더 유리할까요?**
- 서브: 방향은 무료에서 봤으니 이제 이유·타이밍·행동을 본다 / 생년월일 운세가 아니라 내 직무·목표·상황 반영
- **세 가지 선택 비교** (점수는 블러 처리)
- **왜 · 언제 · 어떻게** 세 묶음:
  - 왜 → 유리한 이유(흐름·강약 요소·환경 궁합 근거)
  - 언제 → 6개월 중 힘 실리는/조심할 시기
  - 어떻게 → 지금 할 것·피할 것, 조건 우선순위
- 앞으로 6개월 커리어 흐름 (앞 2개월만 공개, 나머지 🔒)
- 내 상황을 하나 더 물어보는 추가 질문 예시
- CTA: `내 커리어 선택 리포트 열기 · {가격}` / `내 수호신 다시 보기`

---

## Screen 6. 결제 후 개인화 입력 (PersonalizeScreen)

**목표: 맞춤 정확도.** 결제 완료 후 직무·목표·현재 상황을 한 화면에서 받는다(건너뛰기 가능).
입력을 반영해 AI 리포트를 생성한다.

---

## Screen 7. 유료 리포트 (ResultScreen · 해금 상태)

단순 사주 설명이 아니라 **커리어 의사결정 리포트**로 구성한다.

1. **지금의 결론** — 한 문장 + 지금 먼저 할 일
2. **이 판단이 나온 이유 · 핵심 시기** — 가장 좋은 이직/협상 시기, 조심할 시기
3. **앞으로 6개월 흐름 · 이후 전망** — 구간별 타임라인 (확장 가능)
4. **행동 가이드** — 지금 해야 할 것 / 꼭 조심할 것
5. **나에게 맞는 환경** — 오행 성향(레이더), 캐릭터 연결(왜 이 선택이 잘 맞나)
6. **추가 질문** — 내 사주 근거로 하나 더 (공유 시 1회 추가 해금)
7. **커리어 성향 공유 카드** — 캐릭터 중심, 개인정보 배제

하단 고지: 명리학 기반 참고 자료 · 오락/자기성찰 목적 · 중요한 결정은 현실 조건과 함께 검토.

## 부록. A/B 테스트 포인트

- 랜딩 카피 (`?c=a` / `?c=b`)
- 가격 (`?p=6900` / `?p=8900`)
- 결과 화면에서 **공유 장치 ↔ 무료 커리어 신호**의 노출 순서
