# 직장인 이직사주 — Codex Handoff Package

이 패키지는 **직장인 이직사주** 앱의 초기 제품 기획과 확정된 의사결정을 Codex로 넘기기 위한 핸드오프 문서입니다.

## 프로젝트 한 줄 정의

> 생년월일시와 현재 커리어 상황을 입력하면, 정통 사주 계산을 기반으로 현재의 이직·잔류·협상 타이밍을 직장인의 언어로 해석해 주는 마이크로 유료 앱.

## 현재 상태

- 아이디어 확정: **직장인 이직사주**
- 플랫폼 방향: **하나의 코드베이스 → iOS + Android**
- 제품 방향: **커뮤니티형이 아닌 Single-player Micro App**
- 사주 방식: **규칙 기반 사주 계산 + AI 해석의 하이브리드**
- 개인화 방식: **생년월일시 + 현재 커리어 상황 2~3문항**
- 구현은 아직 시작하지 않음
- 다음 단계: 제품 설계 검토 → 구현 계획 → MVP 개발

## 중요 원칙

이 앱은 "종합 사주 앱"이 아니다.

핵심 질문은 하나다.

> **지금 이직해도 될까?**

그리고 결과는 최소한 아래 3개 판단을 중심으로 제공한다.

- 이직
- 잔류
- 협상

AI는 사주를 임의로 만들어내는 엔진이 아니라,
**규칙 기반 사주 계산 결과를 직장인의 언어로 번역하는 해석 레이어**로 사용한다.
