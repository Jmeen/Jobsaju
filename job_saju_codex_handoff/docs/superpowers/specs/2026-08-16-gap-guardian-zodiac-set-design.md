# 갑목 십이지 수호 캐릭터 10종 디자인

## 목표

기존 `갑자`(쥐)와 `갑진`(용) 2D 캐릭터를 기준으로, 갑목 십이지 세트를 완성할 나머지 10종을 제작한다. 완성 이미지는 잡사주 화면의 다양한 배경과 카드 위에 재사용할 수 있어야 한다.

## 공통 비주얼 규칙

- 기존 2D 갑자·갑진과 같은 포근한 동화책 수채화 질감과 둥근 아기 동물 비율을 사용한다.
- 갑목을 나타내는 연한 하늘색을 몸의 주조색으로 사용한다.
- 큰 청록색 눈, 옅은 분홍 볼, 크림색 주둥이·배·발끝을 공통 특징으로 유지한다.
- 초록색 새싹 문양 복주머니, 금색 매듭과 작은 방울을 공통 복식으로 사용한다.
- 각 동물은 머리부터 발끝까지 보이는 단독 전신 캐릭터로 중앙에 배치한다.
- 자세와 표정은 각 동물의 특징이 한눈에 드러나게 하되 전체 세트의 귀여움과 비율을 통일한다.

## 배경과 출력

- 정사각형 PNG 한 장에 캐릭터 한 종을 담는다.
- 배경은 실제 알파 채널이 있는 완전 투명 배경으로 만든다.
- 바닥 그림자, 배경색, 종이 질감, 장식용 잎·구름·점·반짝이 등 캐릭터 밖의 요소를 넣지 않는다.
- 털, 수염, 갈기, 꼬리 가장자리에 흰 테두리나 색 번짐이 없는 깨끗한 컷아웃을 유지한다.
- 글자, 로고, 워터마크를 넣지 않는다.
- 최종 파일은 `assets/baby-guardians/2d/`에 저장한다.

## 생성 방식과 검수

10종을 각각 별도의 이미지 생성 요청으로 제작한다. 두 기존 이미지는 스타일 참조로만 사용하며 원본을 변경하지 않는다. 각 결과물은 동물 식별성, 공통 색상과 복식, 전신 누락 여부, 투명도, 불필요한 배경 요소, 손발·꼬리 등 해부학적 오류를 확인한다. 문제가 있는 이미지만 해당 항목을 명시해 한 차례씩 수정한다.

## 범위 제외

- 기존 갑자·갑진 이미지의 투명 배경 변환
- 3D 캐릭터 스타일
- 앱 코드나 캐릭터 선택 로직 변경
- 을목 이후 천간 캐릭터 제작
