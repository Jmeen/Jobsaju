# PRODUCT SPEC — 잡사주 (직장인 수호신 → 커리어 판단)

## 0. 한 줄 정의

> 잡사주는 **직장인 수호신 캐릭터**로 가볍게 진입해,
> 개인화된 **이직·잔류·협상 판단**과 **커리어 흐름**으로 확장되는 서비스다.

랜딩은 “이직 사주 서비스”가 아니라 **캐릭터 발견** 경험이다.
사주 용어를 몰라도, 캐릭터로 들어와 자기 커리어 판단까지 자연스럽게 이어지게 만든다.

### 핵심 역할 분담

| 요소 | 역할 | 목표 |
| --- | --- | --- |
| **수호신 캐릭터** | 유입과 공유 이유 | 클릭 · 자기 동일시 · 공유(바이럴) |
| **무료 커리어 신호** | 유료 전환의 연결고리 | “그래서 지금 뭐가 유리한데?” → “왜?”라는 질문 생성 |
| **상세 커리어 리포트** | 결제 이유 | 왜·언제·어떻게에 답하는 의사결정 리포트 |

1차 목표는 **바이럴**이다. 결과 화면에서 바로 결제만 밀지 않는다 —
캐릭터에 애착이 생긴 뒤 공유하게 하고, 그다음에 커리어 판단으로 넘긴다.

---

## 1. 제품 목표

직장인이 이직/잔류/협상과 관련한 불확실성을 느낄 때,
복잡한 사주 용어를 몰라도 자신의 흐름을 **커리어 의사결정 언어**로 이해하도록 돕는다.

앱은 미래를 확정적으로 예언하는 도구가 아니라,
사주 기반의 엔터테인먼트/자기성찰 프레임으로 의사결정 관점을 제공한다.

---

## 2. 핵심 사용자

### Persona A — 이직 고민 직장인
- 지금 회사가 답답하지만 퇴사까지 확신은 없음
- 올해가 움직일 시기인지 궁금함

### Persona B — Offer 보유자
- 이미 채용 제안을 받음
- 지금 수락하는 게 좋은 흐름인지 궁금함

### Persona C — 조건 협상자
- 연봉/직급/역할 협상 중
- 언제, 어떤 태도로 움직일지 궁금함

세 페르소나 모두 **캐릭터(수호신)로 먼저 진입**한다. 커리어 고민은 그다음에 붙는다.

---

## 3. 핵심 Job To Be Done

> “내 캐릭터가 재미있고, 그 결과가 지금 내 커리어 판단(이직·잔류·협상)과 연결됐으면 좋겠다.”

무료는 **“그래서 지금 뭐가 유리한데?”** 까지 답한다.
유료는 **“왜 그렇고, 언제, 어떻게 움직여야 하는데?”** 에 답한다.

---

## 4. 무료 / 유료 경계 (Freemium)

경계를 흐리지 않는 것이 이 제품의 핵심 원칙이다.

### [무료 영역]
- **내 수호신** (60갑자 캐릭터, 아트워크)
- **캐릭터 설명** (한 줄 성격 + 왜 이 수호신인지)
- **같이 일하면 잘 맞는 유형** (찰떡 / 부딪히는 유형 — 세계관 확장·공유 장치)
- **무료 커리어 신호**: 이직 / 잔류 / 협상 우선순위(◎ ○ △)
- **한 문장 커리어 판단** (방향만: 예 *“지금은 바로 움직이기보다, 현재 자리에서 조건을 먼저 끌어올리는 흐름이 강해요.”*)

> 무료는 **방향**만 준다. 세부 점수·긴 분석·타이밍·행동은 주지 않는다.

### [유료 영역] — 커리어 의사결정 리포트
1. **지금의 결론** — 한 문장 (예: *“지금은 이직보다 협상이 우선입니다.”*)
2. **이 판단이 나온 이유** — 커리어 흐름, 강한/약한 요소, 환경과의 궁합, 다른 선택 대비 우세 근거
3. **6개월 흐름** — 구간별 타임라인 (예: 협상/조건 조정 → 외부 기회 탐색 → 실제 이동 판단)
4. **행동 가이드** — 지금 할 것 / 피할 것, 이직 준비 시 볼 조건, 협상 시 우선 조건
5. **맞는 환경** — 잘 맞는 조직·업무 방식, 주의할 환경 (수호신 캐릭터 설명과 연결)
6. **질문별 상세 해석** — 내 상황을 하나 더 물어보는 추가 질문
7. **SNS 공유 카드** — 개인정보 배제, 캐릭터·닉네임·한 줄 설명 중심

> 유료 CTA는 “상세 리포트 보기(정보량 추가)”가 아니라 **왜·언제·어떻게**를 판다.
> 무료에서 이미 보여준 방향(예: 이직 ◎)을 이어받아, 그것이 왜 유리한지로 연결한다.

---

## 5. 비즈니스 및 유료화 모델 (Unlock)

* **배포 모델**: 모바일 브라우저에 최적화된 반응형 웹.
* **유료화 방식**: **1회 상세 리포트 Unlock 결제** (기본 8,900원, A/B로 6,900원).
  * 결제 완료 시 로컬 저장소·이메일 링크로 언제든 다시 열람.
  * 포트원(PortOne) 연동 — 카카오페이, 네이버페이, 간편카드결제.
* **공유 인센티브**: 결제자가 결과를 공유하면 추가 질문 1회 해금.

## 6. MVP에서 제외

- 회원가입 / 로그인
- 커뮤니티 / 사용자 게시물
- **실제 두 사람 간 사주 궁합 상품** (‘같이 일하면 잘 맞는 유형’은 캐릭터 세계관·공유 장치일 뿐, 생년월일 2개를 받지 않는다)
- 연애운 / 건강운 / 종합 사주
- 실시간 상담 / 인간 역술가 연결
- 구독 / 복잡한 SNS 기능

---

## 7. 성공 지표

**Primary (바이럴 루프)**
1. 결과 화면 공유율 (공유 시도 / 결과 완료)
2. 공유 유입자의 결과 완료율 (K-factor)

**전환·매출**
3. 유료 결제 발생 · 결제 전환율
4. 카테고리 유료 Top 10 → Top 3 → #1

**보조**
5. 앱스토어/스토어 평점

비핵심: DAU · MAU · 커뮤니티 활성도

## 8. 최종 퍼널

| # | 화면 | 감정/목표 |
| --- | --- | --- |
| 1 | 랜딩 | 나는 어떤 수호신인가? → **클릭** |
| 2 | 출생정보 입력 | 최소 마찰 → **완료** |
| 3 | 무료 수호신 결과 | 재미 + 자기 동일시 → **“나랑 비슷한데?”** |
| 4 | 공유 장치 (같이 일하면 잘 맞는 유형) | 친구가 떠오름 → **공유** |
| 5 | 무료 커리어 신호 (◎○△ + 한 문장) | 방향 확인 → **“왜?”** |
| 6 | 유료 전환 (왜·언제·어떻게) | 근거·타이밍·행동을 원함 → **결제** |
| 7 | 유료 리포트 | 실제 판단·행동 가이드 → **만족 / 재방문** |

> 화면 3~5는 실제로 한 화면(무료 수호신 결과)에서 스크롤로 이어진다:
> 수호신 → 캐릭터 설명 → 같이 일하면 잘 맞는 유형 + 공유 → 무료 커리어 신호 → 유료 전환 CTA.
> 공유와 무료 신호의 순서는 화면 길이에 따라 A/B 테스트 가능하다.

자세한 화면 사양은 [UX_FLOW.md](./UX_FLOW.md) 참고.
