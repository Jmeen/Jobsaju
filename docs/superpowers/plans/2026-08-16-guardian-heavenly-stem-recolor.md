# Guardian Heavenly Stem Recolor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 승인된 잡사주 60갑자 캐릭터의 디자인을 보존하면서 천간별 청·적·황·백·흑 주조색이 몸에서 명확히 읽히도록 재색상한다.

**Architecture:** 기존 PNG 한 장을 하나의 편집 대상으로 삼아 built-in ImageGen으로 한 번에 한 캐릭터씩 재색상한다. 결과는 임시 검수 폴더에서 RGBA·투명도·불변조건을 확인한 뒤 production 파일을 교체하며, 12동물별 5색 비교 시트와 전체 시트로 최종 검수한다.

**Tech Stack:** built-in ImageGen, PowerShell, Python/Pillow 검증 스크립트, 기존 `tmp/review_guardians.py`

## Global Constraints

- 얼굴 구조, 눈 모양, 표정, 포즈, 머리·몸 비율을 변경하지 않는다.
- 운주머니 위치·크기·심볼과 대표 소품을 유지한다.
- 오행은 팔레트 계열과 시그니처 포인트를 통제하며 몸 전체를 경직되게 단색 교체하지 않는다.
- 기존 동물별 대표 몸색을 우선 보존하고 보조색·무늬·음영·운주머니·소품에 오행색을 분산한다.
- 목 캐릭터는 푸른색·청색·청록색 몸색을 허용하고 녹색은 새싹·운주머니 등 포인트 중심으로 사용한다.
- 갑·을은 푸른색·청색·청록색 몸색과 녹색 포인트, 병·정은 코랄·주홍·살구·연한 적색, 무·기는 크림·황토·베이지·머스터드, 경·신은 아이보리·백색·은회색과 샴페인 골드, 임·계는 네이비·먹색·차콜·짙은 블루그레이를 사용한다.
- 순검정, 순백, 형광색, 고채도 원색을 금지한다.
- 흑색군을 파란 캐릭터처럼 처리하지 않고 백색군을 미채색처럼 보이게 하지 않는다.
- 배경·체크무늬·워터마크·문자를 만들지 않고 실제 투명 PNG를 유지한다.
- 기존 파일을 덮어쓰기 전에 원본 60종을 백업한다.
