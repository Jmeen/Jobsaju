# 생년월일·시간 휠 피커 설계

## 목표

생년월일과 출생시간의 숫자 입력칸을 모바일에서 손가락으로 위아래 스크롤해 선택하는 휠 피커로 교체한다. 사용자는 키보드를 열지 않고도 날짜와 시간을 입력할 수 있어야 한다.

## 화면 구성

- 기존 성별 및 양력·음력 선택은 유지한다.
- 생년월일은 `연도 / 월 / 일` 3열 휠로 표시한다.
- 출생시간은 `시 / 분` 2열 휠로 표시한다.
- 각 휠은 위·아래 항목을 흐리게, 중앙 선택 항목을 밝고 크게 표시한다.
- 중앙에는 선택 영역을 나타내는 한 쌍의 가로선을 둔다.
- 각 열의 단위인 `년`, `월`, `일`, `시`, `분`을 선택값 옆에 표시한다.
- 현재의 어두운 핀테크/SaaS 디자인과 보라색 포인트 컬러를 유지한다.

## 값과 범위

- 연도: 1920년부터 현재 연도까지, 최신 연도가 위쪽에 오도록 표시한다.
- 월: 1~12월.
- 일: 선택한 연·월의 실제 일수만 제공한다. 윤년 2월은 29일까지 제공한다.
- 시: 0~23시.
- 분: 0~59분, 1분 단위.
- 기존 기본값 `1993-08-12 13:30`은 유지한다.
- 사용자가 월이나 연도를 바꿔 현재 선택한 일이 존재하지 않게 되면 해당 월의 마지막 날로 자동 보정한다.

## 상호작용

- 손가락, 마우스 휠, 트랙패드 스크롤을 지원한다.
- 스크롤이 멈추면 가장 가까운 항목이 중앙에 스냅되고 즉시 `birthData`에 문자열 값으로 반영된다.
- 항목을 누르면 해당 항목이 중앙으로 부드럽게 이동한다.
- 키보드 포커스 후 위·아래 방향키로 한 칸씩 변경할 수 있다.
- `출생시간 모름`을 선택하면 시간 휠을 숨기고 기존 삼주 분석 로직을 그대로 사용한다.
- 저장된 세션이 있으면 저장된 값의 위치로 휠을 초기화한다.

## 컴포넌트 경계

- `WheelPicker`: 숫자 목록 한 열의 렌더링, 스크롤 스냅, 클릭, 키보드 선택을 담당한다.
- `BirthDateTimePicker`: 연·월·일과 시·분 휠을 조합하고 월별 일수 보정을 담당한다.
- `App`: 기존 `birthData` 상태를 소유하고 `BirthDateTimePicker`에 값과 변경 콜백을 전달한다.

## 접근성

- 각 휠은 의미 있는 `aria-label`과 `listbox` 역할을 가진다.
- 각 항목은 `option` 역할과 선택 상태를 제공한다.
- 중앙 선택값은 텍스트로도 명확하게 보여 색상에만 의존하지 않는다.
- `prefers-reduced-motion` 환경에서는 부드러운 스크롤 애니메이션을 최소화한다.

## 검증

- 윤년과 평년의 2월 일수 테스트.
- 31일에서 30일 월로 이동할 때 마지막 날 보정 테스트.
- 스크롤 위치에서 가장 가까운 항목을 선택하는 계산 테스트.
- 시간 모름 선택 시 시간 휠이 사라지는 컴포넌트 계약 확인.
- 전체 테스트, 린트, 프로덕션 빌드 실행.
- 모바일 너비에서 휠이 잘리지 않고 세 열이 한 화면에 표시되는지 수동 확인.

## 범위 제외

- 양력·음력 변환 로직 변경.
- 사주 계산 방식 변경.
- 외부 날짜 선택 라이브러리 추가.
- 무한 반복 휠 및 진동 피드백.
