# 공유 효용 문구 설계

## 목표

공유받은 사람이 친구의 결과 유형에 호기심을 느끼고, 자신이 얻을 수 있는 `6개월 이직 로드맵`과 `직접 질문` 기능을 이해한 뒤 클릭하도록 한다.

## 확정 문구

- 개인화 제목: `나는 {결과 유형}이래. 너는 지금 옮겨도 될까?`
- 설명: `내 사주로 앞으로 6개월 이직 타이밍을 확인하고, 내 고민도 직접 질문해보세요.`
- 카카오 버튼: `내 6개월 이직운 보기`
- 기본 URL 제목: `지금 옮길까, 남을까? 6개월 이직 로드맵`
- 기본 URL 설명: `내 사주와 실제 고민을 분석하고, 궁금한 점까지 직접 질문해보세요.`

## 범위

카카오 맞춤 피드, Web Share 텍스트, Open Graph, Twitter 카드 문구를 일치시킨다. 이미지와 공유 보너스 지급 조건은 변경하지 않는다.

## 검증

결과 유형별 제목, 카카오 설명과 CTA, 기본 URL 메타데이터를 자동 테스트한다.
