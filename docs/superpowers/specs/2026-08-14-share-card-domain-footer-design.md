# 공유 이미지 도메인 푸터 변경 설계

## 목표

결과 화면 하단에서 미리 보고 저장하거나 공유하는 800×800 캐릭터 카드에서 전략 요약 문구를 제거하고, 서비스 도메인 `Jobsaju.kr`을 하단에 표시한다.

## 변경 범위

- 실제 화면에 연결된 `src/utils/shareCard.ts`의 공유 카드 Canvas 렌더링만 변경한다.
- `model.conclusion`을 최대 두 줄로 그리는 하단 전략 요약 블록을 제거한다.
- 전략 요약 블록 위의 가로 구분선을 제거한다.
- 기존 하단 CTA 문구를 `Jobsaju.kr`로 교체한다.
- 결과 페이지 본문과 상세 리포트의 `one_line_conclusion`은 유지한다.
- 카드의 캐릭터, 제목, 점수, 컬렉션 번호 등 나머지 구성은 유지한다.
- 현재 화면에 연결되지 않은 이전 400×400 렌더러는 이번 변경 범위에서 제외한다.

## 구현 방식

공유 카드 전용 렌더러에서 구분선과 결론 텍스트의 Canvas 호출을 삭제한다. 하단에는 기존 푸터의 위치와 스타일을 사용해 `Jobsaju.kr`을 그린다. 카드 모델의 `conclusion` 필드는 다른 호출부와의 호환성을 위해 이번 작업에서는 제거하지 않는다.

## 결과 레이아웃

캐릭터와 세 가지 점수 영역 아래에는 전략 요약이나 구분선을 표시하지 않는다. 이미지 하단 좌측에 `Jobsaju.kr`만 표시한다. 제거된 결론 영역은 새로운 문구로 채우지 않아 카드가 더 단순하게 보이도록 한다.

## 검증

- Canvas 렌더러가 `model.conclusion`을 그리지 않는지 단위 테스트로 확인한다.
- 하단에 정확히 `Jobsaju.kr`이 그려지는지 단위 테스트로 확인한다.
- 관련 테스트와 TypeScript 빌드를 실행한다.
- 가능하면 로컬 화면에서 카드 미리보기에 전략 요약이 없고 도메인이 표시되는지 확인한다.
