# 공유 보너스 질문 UX 설계

## 목표

리포트 구매자는 추가 질문 1회를 기본으로 사용하고, 친구 공유가 실행되면 질문 1회를 더 사용할 수 있다. 공유 메시지는 결과 유형을 드러내 친구의 호기심을 유도한다.

## 확정 동작

- 기본 질문 한도는 1회, 공유 보너스 적용 후 총 2회다.
- 공유 문구는 최고 점수 축에 따라 `나는 잔류형이라는데, 너는?`, `나는 이직 준비형이라는데, 너는?`, `나는 협상형이라는데, 너는?` 중 하나다.
- 카카오 CTA는 `내 사주도 확인하기`다.
- Kakao, Web Share 링크, Web Share 파일 공유가 실행된 경우에만 보너스를 지급한다. 취소와 다운로드 대체는 지급하지 않는다.
- 질문 영역은 상세 리포트 아래, `내 이직운 캐릭터 & 백분위 카드` 바로 위에 둔다.
- 첫 답변 뒤에는 `친구에게 공유하고 한 번 더 물어보기` 버튼을 노출한다.
- 서버 KV는 기본 질문과 보너스 질문 사용 여부를 별도 키로 기록한다. 두 번째 질문은 공유 보너스 키가 있어야 허용한다.
- 기존 단일 `followUp` 저장 세션은 배열 형태로 호환 복원한다.
- 헤더의 `결` 표식과 무료 결과 카드 미리보기는 제거한다.

## 오류 처리

- 공유 보너스 등록에 실패하면 질문권을 지급하지 않고 재시도를 안내한다.
- AI 답변 실패 시 해당 질문권은 소진하지 않는다.
- 두 질문을 모두 사용하면 입력 대신 사용 완료 상태를 보여준다.

## 검증

- 결과 유형별 공유 후킹 문구 단위 테스트
- 공유 결과별 보너스 지급 조건 단위 테스트
- 서버의 두 번째 질문 허용 및 세 번째 질문 차단 테스트
- 전체 테스트, 린트, 프로덕션 빌드
