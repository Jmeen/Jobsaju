# 사업자 정보 공통 푸터 디자인

## 목적

잡사주의 모든 사용자 화면에서 서비스 운영 주체와 고객지원 정보를 일관되게 확인할 수 있게 한다.

## 표시 범위와 배치

- `App`의 공통 최상위 컨테이너 마지막에 하나의 푸터를 배치한다.
- 인트로, 입력, 로딩, 결과 화면에서 모두 렌더링한다.
- 화면에 고정하지 않고 각 화면 콘텐츠 다음의 일반 문서 흐름에 둔다.
- 팝업과 모달 내부에는 푸터를 중복 표시하지 않는다.

## 표시 내용

푸터에는 다음 내용을 순서대로 표시한다.

1. `잡사주 | 운영: 두리하나랩`
2. `대표 임재민 · 사업자등록번호 306-16-54574`
3. `고객지원: support@jobsaju.kr`
4. `이용약관 · 개인정보처리방침 · 환불정책`

고객지원 이메일은 `mailto:support@jobsaju.kr` 링크로 제공한다. 정책 문서 세 항목은 실제 문서가 준비되기 전까지 링크가 아닌 비활성 텍스트로 표시한다.

## 시각 디자인

- 기존 어두운 모바일 UI와 조화를 이루는 작은 회색 보조 텍스트를 사용한다.
- 상단에 얇은 구분선을 두어 본문과 푸터를 구분한다.
- 중앙 정렬하고 여러 줄 사이에 충분한 행간을 둔다.
- 이메일 링크에는 키보드 포커스 표시와 기존 강조색을 사용한다.
- 모바일 폭에서 사업자 정보가 넘치거나 가로 스크롤을 만들지 않게 줄바꿈을 허용한다.

## 접근성

- 시맨틱 `footer` 요소를 사용한다.
- 이메일 주소는 실제 링크로 제공한다.
- 아직 동작하지 않는 정책 항목은 링크나 버튼으로 표현하지 않아 오작동 기대를 만들지 않는다.

## 검증

- 푸터 컴포넌트 테스트에서 운영자명, 대표자명, 사업자등록번호, 지원 이메일, 정책명 세 가지가 모두 렌더링되는지 확인한다.
- 이메일 링크의 `href`가 `mailto:support@jobsaju.kr`인지 확인한다.
- 정책명이 링크로 렌더링되지 않는지 확인한다.
- 전체 테스트와 프로덕션 빌드를 실행한다.

## 제외 범위

- 이용약관, 개인정보처리방침, 환불정책의 실제 페이지 및 문안 작성
- 정책 페이지 라우팅
- 푸터 고정 또는 접기/펼치기 기능
